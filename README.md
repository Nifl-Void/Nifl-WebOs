# ᛟ NiflOS (Nifl-Void OS)

A minimal, Norse-inspired web operating system running entirely within a single file (`index.html`). This project combines the mysterious atmosphere of ancient runes with modern cyber tools in the browser.

## 🛠️ Key Modules & Features
* **Matrix Engine (`#00f0ff` / Gold / Blood):** Live background rendered via HTML5 Canvas with falling Norse runes.
* **Nifl-Chronos:** Norse timer and calendar with watch guard tracking and a rune fate generator.
* **Nifl-Link (Ritual Assembly):** P2P voice communication built on PeerJS featuring a visual microphone sensitivity meter.
* **Nifl-Notes:** A notepad module with automatic saving to `localStorage`, ensuring your thoughts persist even after a system reboot.
* **Nifl-Calc:** A stylish calculator for quick mathematical computations directly within the void.
* **Nifl-Terminal (Heimdall & Sleipnir):** An interactive terminal supporting commands for system management, simulated Wi-Fi network scanning, and real Bluetooth device scanning (`scan bt`).
* **Window Manager:** Fully functional window management with dynamic layering (`z-index`) and screen boundary limiters.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox).
3. *Note:* For full functionality of the voice module (Nifl-Link) and the Bluetooth scanner, running it via a local server (such as Live Server in VS Code) or HTTPS is recommended.
